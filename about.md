# About

**Indian Astronomers Around the World** is an academic initiative to connect Indian astronomers across institutions and countries. The goals are:

- Facilitate scientific exchange and collaborations
- Provide visibility for seminars, workshops, and community events
- Support early-career researchers through networking and mentorship

If you'd like to contribute events, recordings, or host a session, please open a Pull Request with the event Markdown file under `/events/`.
